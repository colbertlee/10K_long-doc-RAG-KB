## 主要问题

### 1. 文档未索引
- **问题**：6个上传的文档中有6个未索引
- **影响**：用户无法通过智能对话和查询检索到这些文档的内容
- **解决方案**：运行批量索引命令

### 2. BM25索引问题
- **问题**：BM25索引虽然有1个文档，但查询不返回结果
- **影响**：BM25 fallback机制无法正常工作
- **解决方案**：重新构建BM25索引

### 3. LightRAG索引问题
- **问题**：LightRAG chunks为0，没有文档被正确索引
- **影响**：LightRAG检索完全依赖BM25 fallback
- **解决方案**：重新索引文档到LightRAG

## 解决方案

### 立即执行
```bash
# 索引所有未索引文档
curl -X POST http://localhost:8000/api/v1/index/all
```
