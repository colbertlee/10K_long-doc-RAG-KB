## 🔧 使用指南

### 系统启动时自动检查
系统启动时会自动检查索引完整性并显示状态，无需手动操作。

### 定时检查
系统每30分钟自动检查一次索引完整性，并在控制台输出检查结果。

### 前端索引状态管理
1. 访问知识管理界面
2. 查看索引状态卡片
3. 点击"刷新索引状态"更新状态
4. 点击"索引所有未索引文档"执行批量索引

### API使用
```bash
# 检查索引完整性
curl http://localhost:8000/api/v1/index/integrity

# 获取未索引文档
curl http://localhost:8000/api/v1/index/unindexed

# 索引所有未索引文档
curl -X POST http://localhost:8000/api/v1/index/all
```

## 🎯 系统行为

### 启动时
1. 初始化异步上下文
2. 检查索引完整性
3. 显示索引统计信息
4. 启动定时索引检查器
5. 根据索引健康状态显示警告

### 运行时
1. 每30分钟自动检查索引完整性
2. 输出检查结果到控制台
3. 根据健康状态触发通知

### 关闭时
1. 清理异步上下文
2. 停止定时索引检查器
