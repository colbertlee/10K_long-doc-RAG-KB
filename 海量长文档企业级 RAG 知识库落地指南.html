💡 核心视角：玩具项目 vs. 企业级工程

❌ 玩具项目思维 (Toy Project)

单文档直接导入 ➔ 固定的 Chunk 长度粗暴切分 ➔ 单线程 Embedding 入库 ➔ 基础向量相似度检索 ➔ 拼接 Prompt 送入 LLM。

✅ 企业级工程思维 (Enterprise Grade)

高吞吐数据流水线 (Pipeline) ➔ 异构清洗与清洗容错 ➔ 结构化语义切片与上下文重叠 ➔ 混合存储与双路召回 ➔ 权限隔离 (RBAC) 与 DataOps 闭环。

🛠️ 架构全流程：6 大核心落地阶段

一、 数据清洗与标准化 (Data Ingestion & Cleaning)
目标：解决“Garbage in, Garbage out”问题，保障数据源头质量。
  • 异构格式解析：对扫描版 PDF 及图片接入高精度 OCR 引擎（如 PaddleOCR/Tesseract）提取文本与表格；对富文本剥离样式代码，保留 DOM 目录结构。
  • 数据去重与过滤：使用局部敏感哈希（MinHash / SimHash）剔除重复文档段落；过滤乱码、页眉页脚及连续空行。
  • 合规脱敏：针对 PII 敏感信息（如身份证、手机号、密钥）在入库前实施掩码掩盖。
二、 结构化智能切片 (Semantic Chunking)
目标：摒弃固定长度（Fixed-size）粗暴切分，保留完整上下文与语义。
  • 基于结构的切片：结合 Markdown/DOM 结构树，优先按照 H1/H2/H3 标题及自然段落边界切分。
  • 滑动重叠窗口（Overlap Window）：保持 10% - 15% 的重叠上下文（如 Chunk=512 tokens，Overlap=64 tokens），防止段落交界处语义断裂。
  • 表格与富文本处理：表格转为 Markdown 或 JSON 文本存储，必要时先由 LLM 生成表格摘要再做索引。
三、 并行化 Embedding 与元数据绑定 (Parallel Processing & Metadata)
目标：突破万级文档的处理吞吐量瓶颈，构建完整数据追溯链。
  • 高性能批处理：采用多进程/分布式任务队列（如 Ray/Celery）提升向量化并发，最大化利用显存与 API 吞吐。
  • 元数据（Metadata）绑定：每个切片深度绑定 `doc_id`、`source`（来源路径）、`hierarchy`（章节层级）、`created_at`（版本时间戳）及 `access_control`（ACL 权限标签）。
四、 混合存储与高性能索引 (Hybrid Storage & Indexing)
目标：支撑海量向量下的低延迟检索与高并发响应。
  • 存储解耦架构：向量库（Milvus/Qdrant）专注存储向量并建立 HNSW 图索引；关系型/文档库（PostgreSQL/ES）存储原文与高维元数据。
  • 双路索引构建：同时搭建“语义向量索引”（捕捉隐式语义）与“文本倒排索引”（BM25，精确匹配专有名词与型号）。
五、 混合召回与重排序 (Hybrid Search & Re-ranking)
目标：提高召回率（Recall）与精准度（Precision），减少大模型幻觉。
  • 多路混合召回：并行执行向量检索 + BM25 关键词检索，通过 RRF（Reciprocal Rank Fusion）算法融合初筛结果。
  • 精细重排序（Re-rank）：将初筛的 Top-K 结果提交给 Re-rank 模型（如 BGE-Reranker）进行交叉注意力打分，截取 Top 3-5 送给 LLM。
六、 自动化运维与闭环监控 (DataOps & Continuous Iteration)
目标：具备“自愈更新”能力，打造可持续演进的产品体系。
  • 增量更新机制：基于 文件 Hash 或 CDC（ Change Data Capture）技术，实现新增/修改文档的自动化增量入库与旧版软删除。
  • 安全与权限隔离（RBAC）：在检索阶段强制注入预过滤条件（Pre-filtering），确保用户只能检索有权限的元数据。
  • 评估闭环：监测 Latency、Hit Rate 等指标，采用 Ragas 等自动化评估工具定期测试，反向优化 Chunk 粒度。

🎯 面试高质表达模版 (3分钟话术)

💬 面试官提问：“如果给你 1 万份长文档构建企业级知识库，你怎么做？”

回答策略：“我不会简单把它当成调用 API 的玩具项目，而是作为一条高可用、工程化的 Data Pipeline 来设计：

  1. 清洗标准化：异构数据走高精度 OCR，通过 MinHash 全局去重与 PII 脱敏。
  2. 结构化切片：按文档 DOM 结构切分，保留 10-15% 的重叠窗口，保证上下文不断裂。
  3. 并行与元数据：多进程批处理提高 Embedding 吞吐，切片强绑定章节、时间戳和 RBAC 权限标签。
  4. 混合存储双索引：向量库与原文数据库解耦，构建向量 HNSW 与 BM25 双路索引。
  5. 混合召回与 Re-rank：向量加关键词双路召回，通过交叉注意力 Re-rank 模型精细打分剔除噪声。
  6. DataOps 闭环：搭设增量更新与动态权限隔离，结合 Ragas 评估指标持续优化流水线。”
